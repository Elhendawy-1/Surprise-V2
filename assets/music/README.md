# Music File

Place your background music file here as `song.mp3`.

## Supported Format
- MP3 (recommended)

## How to Add
1. Place your music file in this directory
2. Name it `song.mp3`
3. The website will automatically use it as background music

## Notes
- Keep file size reasonable (under 5MB recommended)
- The music will loop continuously when playing
- Users can mute/unmute using the controls
